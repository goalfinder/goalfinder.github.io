# Contributing
Thank you for helping improve this project! We welcome bug reports, feature requests, documentation improvements, and security reports.
Before opening an issue, please:
- Search existing issues to avoid duplicates.
- Ensure you are using the latest version of the project.
- Provide as much detail as possible.

## Reporting Bugs
When reporting a bug, please include:

### Summary
Provide a clear and concise description of the problem.

### Environment
- Project version:
- Operating system (if applicable):
- Browser (if applicable):

### Steps to Reproduce

### Expected Behavior
Describe what you expected to happen.

### Actual Behavior
Describe what actually happened.

### Logs and Screenshots
Attach relevant logs, screenshots, stack traces, or other diagnostic information.

### Additional Context
Add any other context that may help identify the issue.

## Suggesting Features
Before opening suggesting an issue, please:

### Problem Statement
Describe the problem or limitation you are experiencing.

### Proposed Solution
Explain the feature or improvement you would like to see.

### Alternatives Considered
Describe any alternative solutions or workarounds.

# Security Policy
## Reporting a Vulnerability
Please **only report minor security vulnerabilities through public GitHub issues** otherwise please contact: `goalfinder@htl-leonding.ac.at`.
When submitting a report, please include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested remediation (if known)
- Affected version
