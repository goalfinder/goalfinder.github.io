# GoalFinder Web App
This page provides detailed instructions on how to use the GoalFinder's Web App

## Opening the Web App
To connect to the web app, first connect to the GoalFinder WiFi network called `GoalFinder XX` or similar (if not set otherwise). In most cases, you should get a notification asking you to log into the network. Follow this prompt to open the web app.
Should this notification not show up or you prefer to open the web app through a web browser, open following site `goalfinder.local` or type the following IP address in the URL text box: `192.168.4.1`. The latter should work in almost all cases.
If none of these work, contact your network administrator or write us an email at `goalfinder@htl-leonding.ac.at`.

## Games
The game page contains a selection of games which can be played using the GoalFinder device
![Games View](content/doc/wa-img/en/3.png)(400)

### Throw-Challenge
The Throw-Challenge is the regular GoalFinder game mode. Each player gets 60 seconds time to try and score a hit or miss. Then it is the next players turn.
Players can be added by typing the players name in the text box at the top and clicking "Add Person". Added players will appear in a list below. You can remove players by clicking the trash icon next to their name.
The Game can be started or paused using the play button.
The web app will show how much time the current player has to score a hit or miss, along the hits and misses of all players.
If the GoalFinder doesn't read a hit or miss properly, the hits and misses for each player can be incremented with the `+` and `-` next to their name.
You can finish the game by pressing the "Finish" button.
![Throw Challenge](content/doc/wa-img/en/4.png)(400)

### Timed-Game-Challenge
In the Time-Game-Challenge each player gets 120 seconds to score as many hits or misses in that time.
Players can be added by typing the players name in the text box at the top and clicking "Add Person". Added players will appear in a list below. You can remove players by clicking the trash icon next to their name.
The Game can be started or paused using the play button.
The web app will show how much time the current player has to score a hit or miss, along the hits and misses of all players.
If the GoalFinder doesn't read a hit or miss properly, the hits and misses for each player can be incremented with the `+` and `-` next to their name.
You can finish the game by pressing the "Finish" button.
![Timed Game Challenge](content/doc/wa-img/en/5.png)(400)

### Free-Play
In Free Play there is no need for setting up players. The device will simply count all hits or misses.
You can start or pause the game with the play button and reset the counter with the "Reset" button.
![Free Play](content/doc/wa-img/en/6.png)(400)

## Settings
### Audio Settings
In the audio settings tab you can adjust the volume of the speakers and change the metronome (tick), waiting, hit and miss sound to your liking.
![Audio Settings](content/doc/wa-img/en/7.png)(400)

### LED Settings
In the LED settings tab you can adjust the brightness of the LED strip and change the animation during the idle state.
![LED Settings](content/doc/wa-img/en/8.png)(400)

### Detection Settings
In the detection settings tab you can change the detection sensitivity by using one of 4 presets.
![Detection Settings](content/doc/wa-img/en/9.png)(400)

### Connection Settings
In the connection settings tab you can change the device name (the WiFi network name) and add a password to it's WiFi network.
You can find a detailed guide on how to connect the device to already existing networks ^[here](../content/doc/en/t-webapp-advanced.md).
![Connection Settings](content/doc/wa-img/en/10.png)(400)

### System Settings
In the system settings tab you can change the theme, accent color and language of the web app. 
You can restart the GoalFinder device using the "Restart" button and reset the device's settings using the "Reset to factory settings button". 
Device updates can be done through this tab, for detailed instructions read the ^[update tutorial](../content/doc/en/u-update.md).
![Connection Settings](content/doc/wa-img/en/11.png)(400)
