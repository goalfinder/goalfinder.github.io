# GoalFinder Web App
This page provides detailed instructions on how to use the GoalFinder Web App.

## Opening the Web App
To connect to the web app, first connect to the GoalFinder WiFi network called `GoalFinder XX` or a similar name (unless configured otherwise). In most cases, you should receive a notification prompting you to log in to the network. Follow this prompt to open the web app.
If this notification does not appear, or if you prefer to open the web app through a web browser, open the following address: `goalfinder.local`, or enter the following IP address into the browser's address bar: `192.168.4.1`. The latter should work in almost all cases.
If none of these options work, contact your network administrator or send us an email at `goalfinder@htl-leonding.ac.at`.

## Games
The games page contains a selection of games that can be played using the GoalFinder device.
![Games View](content/doc/wa-img/en/3.png)(400)

### Throw-Challenge
The Throw-Challenge is the standard GoalFinder game mode. Each player gets 60 seconds to attempt scoring hits or misses. After that, it is the next player's turn.
Players can be added by entering a player's name in the text box at the top and clicking "Add Person". Added players will appear in a list below. Players can be removed by clicking the trash icon next to their name.
The game can be started or paused using the play button.
The web app displays the remaining time for the current player as well as the hits and misses of all players.
If the GoalFinder does not register a hit or miss correctly, the hit and miss counters for each player can be adjusted using the `+` and `-` buttons next to their name.
The game can be finished by pressing the "Finish" button.
![Throw Challenge](content/doc/wa-img/en/4.png)(400)

### Timed-Game-Challenge
In the Timed-Game-Challenge, each player gets 120 seconds to score as many hits or misses as possible within that time.
Players can be added by entering a player's name in the text box at the top and clicking "Add Person". Added players will appear in a list below. Players can be removed by clicking the trash icon next to their name.
The game can be started or paused using the play button.
The web app displays the remaining time for the current player as well as the hits and misses of all players.
If the GoalFinder does not register a hit or miss correctly, the hit and miss counters for each player can be adjusted using the `+` and `-` buttons next to their name.
The game can be finished by pressing the "Finish" button.
![Timed Game Challenge](content/doc/wa-img/en/5.png)(400)

### Free-Play
In Free Play, there is no need to set up players. The device simply counts all hits and misses.
The game can be started or paused using the play button, and the counter can be reset using the "Reset" button.
![Free Play](content/doc/wa-img/en/6.png)(400)

## Settings
### Audio Settings
In the audio settings tab, you can adjust the speaker volume and customize the metronome (tick), waiting, hit, and miss sounds.
![Audio Settings](content/doc/wa-img/en/7.png)(400)

### LED Settings
In the LED settings tab, you can adjust the brightness of the LED strip and change the animation displayed during the idle state.
![LED Settings](content/doc/wa-img/en/8.png)(400)

### Detection Settings
In the detection settings tab, you can adjust the detection sensitivity using one of four presets.
![Detection Settings](content/doc/wa-img/en/9.png)(400)

### Connection Settings
In the connection settings tab, you can change the device name (the WiFi network name) and add a password to the WiFi network.
A detailed guide on connecting the device to existing networks can be found ^[here](../content/doc/en/t-webapp-advanced.md).
![Connection Settings](content/doc/wa-img/en/10.png)(400)

### System Settings
In the system settings tab, you can change the theme, accent color, and language of the web app.
You can restart the GoalFinder device using the "Restart" button and reset the device settings using the "Reset to factory settings" button.
Device updates can also be installed through this tab. For detailed instructions, read the ^[update tutorial](../content/doc/en/u-update.md).
![Connection Settings](content/doc/wa-img/en/11.png)(400)
