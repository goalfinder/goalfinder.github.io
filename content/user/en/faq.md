# FAQ

## Where do I open the Web App?
The Web App can otherwise be opened either [here](http://192.168.4.1) or by opening the IP address `192.168.4.1` in a web browser.
Additional information can be found at ^[Getting to Know the GoalFinder](content/user/en/getting-to-know.md).
**Furthermore, we recommend bookmarking the Web App in the browser to return more easily.**
