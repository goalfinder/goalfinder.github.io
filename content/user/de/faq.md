# Häufige Fragen

## Wo kann ich die Web App öffnen?
Die Web App kann entweder [hier](http://192.168.4.1) oder durch Öffnen der IP-Adresse `192.168.4.1` in einem Webbrowser geöffnet werden.
Mehr Informationen findest du in der Dokumentation zum ^[Kennenlernen des GoalFinders](content/user/en/getting-to-know.md).
**Weiters empfehlen wir, die Web App im Browser zu markieren, um besser zurückkehren zu können.**

## Wie kann ich mein GoalFinder Gerät aktualisieren?
Eine ausführliche Anleitung findest du auf der speziellen Update-Tutorial-Seite ^[hier](content/user/de/update.md).
