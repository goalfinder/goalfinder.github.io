# Häufige Fragen

## Wo kann ich die Web App öffnen?
Die Web App kann sonst entweder [hier](http://192.168.4.1) oder durch öffnen der IP Adresse `192.168.4.1` in einem Webbrowser geöffnet werden.
Mehr Informationen finden Sie in der Dokumentation zum ^[Kennenlernen des GoalFinders](content/user/en/getting-to-know.md).
**Weiters empfehlen wir sich die Web App im Browser zu markieren um besser zurückkehren zu können.**

## Wie kann ich mein GoalFinder Gerät aktualisieren?
Eine ausführliche Anleitung finden Sie auf der speziellen Update-Tutorial-Seite ^[hier](content/user/de/update.md).
