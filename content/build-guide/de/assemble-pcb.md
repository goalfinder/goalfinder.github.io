# Zusammenbau der Leiterplatte
## 1. Leiterplatte montieren
Montieren Sie die elektronischen Komponenten auf der Platine. Als Hilfestellung können der Schaltplan und dass [KiCad-Projekt](https://github.com/htl-leo-club-embedded-iot/GoalFinder/tree/main/blueprint/pcb/1.5) weiterhelfen. Der ToF-Sensor und der Verstärker werden direkt auf der Leiterplatte angebracht.

## 2. Mikrocontroller vorbereiten
Löten Sie die Stiftleisten auf den ESP32 Mikrocontroller. Es können auch nur die tatsächlich benötigten Pins angelötet werden (Details dazu finden Sie im [KiCad-Projekt](https://github.com/htl-leo-club-embedded-iot/GoalFinder/tree/main/blueprint/pcb/1.5)). Setzen Sie den Mikrocontroller entsprechend der Markierung auf der Leiterplatte auf.
