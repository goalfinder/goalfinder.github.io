# Endmontage
## 7. Leiterplatte auf Haupt-Halterung montieren
Verbinden Sie den Erschütterungssensor mit dem 3-poligen JST-Stecker und den Audio-Treiber mit dem Verstärker. Setzen Sie die Leiterplatte auf die Haupt-Halterung – die Durchgangslöcher ermöglichen ein einfaches Einrasten ohne zusätzliche Befestigung.
![PCB Connecting](assets/img/assembly/steps/high_res/GF_assembly_45.jpg)(1020x1228)
*Elektronische Komponenten mit der Leiterplatte verbinden*
![PCB Mounted](assets/img/assembly/steps/high_res/GF_assembly_46.jpg)(1020x1228)
*Leiterplatte auf der inneren Halterung montiert*

## 8. Gehäuse zusammenbauen
Montieren Sie die vier vertikalen Gehäuseplatten rund um das Gerät und befestigen Sie anschließend die obere Platte mit Schrauben.
![Seitenmontage](assets/img/assembly/steps/high_res/GF_assembly_49.jpg)(1020x1228)
*Vertikale Gehäuseplatten werden angebracht*
![Obere Platte montieren](assets/img/assembly/steps/high_res/GF_assembly_54.jpg)(1020x1228)
*Obere Platte wird montiert*

## 9. Firmware hochladen
Besuchen Sie das [GoalFinder Repository](), klonen Sie das Projekt und laden Sie die Firmware mit PlatformIO hoch. Führen Sie `pio run -t upload` und `pio run -t uploadfs` im Verzeichnis `client/embedded/` aus.
