# Mitwirken

Beiträge sind willkommen — einschließlich Fehlerberichte, Funktionsanfragen, Dokumentationsverbesserungen und Code-Änderungen.

### Haben Sie eine Idee?

Wenn Sie eine Idee haben, GoalFinder zu verbessern, öffnen Sie ein Issue mit dem `feature-request` oder `user-story` Label und fügen Sie eine kurze Zusammenfassung und die Motivation hinzu. Bitte fügen Sie keine anderen Labels hinzu — das Projektteam wird Labels nach Bedarf zuweisen.

### Ein Problem gefunden?

Wenn Sie einen Fehler oder falsches Verhalten finden, öffnen Sie ein Issue mit dem `bug` Label und fügen Sie Schritte zur Reproduktion, erwartetes vs. tatsächliches Verhalten, Umgebungsdetails und alle Logs oder Screenshots hinzu. Bitte fügen Sie keine anderen Labels hinzu — das Projektteam wird Labels nach Bedarf zuweisen.

### Möchten Sie Code beitragen?

Forken Sie das Repository und reichen Sie einen Pull Request mit einer prägnanten Zusammenfassung Ihrer Änderungen, verwandten Issues und allen Tests oder Screenshots ein, die das Update demonstrieren.

### Bereits ein Projektmitglied?

Siehe den ^[Beitragsleitfaden](./doc/contribute.mdmd) für detaillierte Anweisungen.
