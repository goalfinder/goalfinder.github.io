# Mitwirken
Beiträge sind willkommen — einschließlich Fehlerberichte, Funktionsanfragen, Dokumentationsverbesserungen und Code-Änderungen.

## Hast du eine Idee?
Wenn du eine Idee hast, GoalFinder zu verbessern, öffne ein Issue mit dem `feature-request` oder `user-story` Label und füge eine kurze Zusammenfassung und die Motivation hinzu. Bitte füge keine anderen Labels hinzu — das Projektteam wird Labels nach Bedarf zuweisen.

## Hast du ein Problem gefunden?
Wenn du einen Fehler oder falsches Verhalten findest, öffne ein Issue mit dem `bug` Label und füge Schritte zur Reproduktion, erwartetes vs. tatsächliches Verhalten, Umgebungsdetails und alle Logs oder Screenshots hinzu. Bitte füge keine anderen Labels hinzu — das Projektteam wird Labels nach Bedarf zuweisen.

## Möchtest du Code beitragen?
Forke das Repository und reiche einen Pull Request mit einer prägnanten Zusammenfassung deiner Änderungen, verwandten Issues und allen Tests oder Screenshots ein, die das Update demonstrieren.

### Bereits ein Projektmitglied?
Lies dir die Dokumentation zu unserem ^[GitHub Verzeichnis](../content/technical/de/github.md) durch, für detaillierte Anweisungen.
